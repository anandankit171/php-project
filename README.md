# 🚀 QueryBoard (PHP project)

> 💬 A simple and interactive discussion platform built with PHP.

---

## 🌟 Features

* 🧑‍💻 User Authentication (Login/Register)
* 🧵 Create & Manage Discussions
* 💬 Comment System
* 🔒 Secure Backend
* 📱 Responsive UI

---

## 🛠️ Tech Stack

* PHP
* MySQL
* HTML, CSS, JavaScript

---

## 📂 Project Structure

```
php-project-discuss/
│── client/
│── common/
│── public/
│── server/
│── .DS_Store
│── index.php
```

---

## ⚡ Setup

```bash
git clone https://github.com/anandankit171/php-project-discuss.git
cd php-project-discuss
```

* Start XAMPP / Apache & MySQL
* Import database in phpMyAdmin
